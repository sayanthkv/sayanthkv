## About me

I'm Sayanth (Sayanth Sajeevan), a full-stack MERN developer with a BCA from Yenepoya University, Bengaluru (2026). I'm currently a MERN Stack Developer Intern at **Softroniics** in Kozhikode, Kerala, working on a team-built learning management system.

I like the parts of web development where correctness and security matter:

- **Concurrency-safe data:** Mongoose ACID transactions to stop double bookings under race conditions
- **Real-time systems:** WebSockets with Socket.io, plus scheduled jobs with `node-cron`
- **Secure access:** JWT, Google OAuth 2.0 and role-based access control
- **Security mindset:** web application penetration testing, ethical hacking and bug bounty hunting
- **Typed code:** TypeScript across the frontend and backend of newer projects

📍 Kannur / Kozhikode, Kerala, India
