### 👨‍💻 About Me

I'm a **Full-Stack MERN & TypeScript Developer** from **Kannur, Kerala**, currently working as a **MERN Stack Developer Intern at Softroniics** (Kozhikode) after completing my **BCA at Yenepoya University** (2026). 

I focus on building production-ready web architectures—from concurrency-safe booking engines and real-time recruitment pipelines to interactive React interfaces—while actively exploring **Web Application Penetration Testing and Bug Bounty hunting**.

- 🔭 **Currently building:** Syllabus & Schedule management modules for the **Softroniics LMS** and refining **Parkora**.
- 🛡️ **Security focus:** OWASP Top 10, authentication hardening (JWT & OAuth 2.0), and web vulnerability research.
- 🌱 **Next up:** Next.js architecture and advanced offensive web security.
